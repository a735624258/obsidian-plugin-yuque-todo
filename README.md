# Obsidian 语雀待办

语雀风格的待办清单体验。点击待办项自动标记完成并添加戳。

## 功能

- 增强 Obsidian 原生 checklist 交互
- 点击未完成项 → 自动勾选 + 添加完成时间戳
- 点击已勾选项 → 取消勾选
- 状态变更实时写入源文件

## 使用

1. 在笔记中写 `- [ ] 待办事项`
2. 阅读模式下点击复选框
3. 自动标记 `[x]` 并追加完成时间

## 安装

下载 `main.js`、`manifest.json`、`styles.css`，放入 `.obsidian/plugins/yuque-todo/`，重启 Obsidian 启用。
